# Security

The scripts in this repository are read-only and never send data over the network.

If you find a security problem — a script that could leak a secret, run something it should not, or be tricked
by a crafted repository — please report it privately through GitHub's
[private vulnerability reporting](../../security/advisories/new) for this repository rather than opening a
public issue. You will get an answer, and credit if you want it, once a fix is released.
